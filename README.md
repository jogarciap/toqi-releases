# Toqi — instaladores

Asistencia e inscripciones con llaveros NFC para gimnasios. App para Windows.

**Descarga directa (siempre la última versión):** [Descargar Toqi-Setup.exe](https://github.com/jogarciap/toqi-releases/releases/latest/download/Toqi-Setup.exe)

```
https://github.com/jogarciap/toqi-releases/releases/latest/download/Toqi-Setup.exe
```

Ver todas las versiones y notas: [Releases → Latest](https://github.com/jogarciap/toqi-releases/releases/latest)

- Requiere un lector NFC USB (ACS ACR122U) y el **llavero maestro** que viene con el servicio: sin él, la app no se activa.
- Las apps instaladas se actualizan solas desde aquí.
- Este repositorio solo contiene instaladores. El código no es público.
- Toqi se llamaba antes Pulso: las versiones 0.1.x se publicaron con ese nombre.
