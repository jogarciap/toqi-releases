# Pulso — instaladores

Asistencia e inscripciones con llaveros NFC para gimnasios. App para Windows.

**Descargar la última versión:** [Releases → Latest](https://github.com/jogarciap/pulso-releases/releases/latest) → `Pulso-Setup-x.y.z.exe`

- Requiere un lector NFC USB (ACS ACR122U) y el **llavero maestro** que viene con el servicio: sin él, la app no se activa.
- Las apps instaladas se actualizan solas desde aquí.
- Este repositorio solo contiene instaladores. El código no es público.
